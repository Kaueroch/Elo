# Elo

Você gerencia clientes atendidos — livro-caixa de atendimentos (nome, valor, data, origem) com painel mensal. Monorepo: back-end Spring Boot (API REST + PostgreSQL) e front-end React.

Este projeto usa o fluxo **SDD** (Spec-Driven Development).
Consulte o [`AGENTS.md`](./AGENTS.md) para configuração específica:
stack, gates de qualidade, issue tracker, branches, integrações e restrições.
